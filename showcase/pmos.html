Getting started

No need to read the repo docs — the AI uses them. You do this:

In Cursor

  1. Clone the repo and open the folder in Cursor.
  2. In chat, type @new-feature or say “I want to start a new feature.”
  3. Give a short name (e.g. smart-notifications).
  4. Answer the PM POV and feature-context questions (one at a time).
  5. Pick an artifact (Product Brief is the default). The AI drafts, runs reviews, and revises.

In Claude Code

  1. Clone the repo and open it in Claude Code.
  2. Same as Cursor: say “I want to start a new feature” (Claude reads CLAUDE.md automatically).
  3. Give a short feature name, then answer the PM POV and feature-context questions.
  4. Choose an artifact; Claude runs the workflow.

First time only: fill in System/company-context.md with your vision and goals so every artifact is grounded in your strategy.
